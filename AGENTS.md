# github-profile agent instructions

The GitHub profile README for `davidjonidev`, rendered at
[github.com/davidjonidev](https://github.com/davidjonidev). One file, `README.md`. No build, no
dependencies, no deploy: GitHub renders whatever is on `main`.

Real file is `AGENTS.md`; `CLAUDE.md` is a symlink to it.

## 🔴 THIS REPO IS PUBLIC. Everything in it, including this file and `docs/memory/`, is world-readable.

The other fleet repos are private and their brains hold internal reasoning. **This one does not get
that luxury.** Never write here: rates or day rates, availability strategy or negotiating positions,
client names not already public on davidjoni.dev, employer-sensitive context, anything about work
being sought, or anything from `applicator/profile.md`. If a fact belongs in the private corpus, it
belongs there and not here, even in a decisions entry explaining a change made to this file.

When in doubt, write the change down in `ops` and leave a pointer here with no detail.

## 🔴 This repo is DOWNSTREAM of `~/business/portfolio`, and holds no facts of its own

`portfolio/content/` is where "who David is" is maintained: `cv.json`, `site.json`, and the case
studies in `content/projects/`. **This README must never restate any of it.**

It used to. It carried a full CV: employment history, project write-ups, a skills matrix, languages,
personal details. By the time anyone checked, it had drifted from the corpus in several places at
once, including showing a former employer as current, and describing a project at a different stage
of delivery than the CV did. **A reader comparing this page against the CV would have found the
contradiction before David did.**

So the rule is the fleet rule, applied here: **write it once, point at it.** If you are about to add
a fact about David to this file, that fact belongs in `portfolio/content/` and this file should link
to where it renders. The correct size of this README is roughly what it is now.

**A link is not a copy.** Naming a public repo and saying what it does is fine. Restating the CV
around it is not.

## Changing it

There is nothing to run. Edit `README.md`, commit, push. GitHub picks it up.

House style follows davidjoni.dev: **no em dashes or en dashes** (the loudest AI tell, banned across
David's writing), engineer-first, dry, no marketing puffery.
